# Startbd Hub

Build startBD.com discovery hub — the master portal and discovery hub for Bangladesh's first integrated AI ecosystem.

Key requirements:
1. Brand & Header:
   - Modern, high-trust tech brand identity for startBD.com ("বাংলাদেশের প্রথম সমন্বিত এআই ইকোসিস্টেম").
   - Bilingual language switcher (English / বাংলা) across the entire UI.
   - Quick navigation to AI Core, Verticals, Free Tools, Roadmap, and Developer Hub.
   - "One Account" Sign In / Early Access CTA.

2. Hero Section:
   - Compelling headline and subhead highlighting one account, one AI core (BDai), and niche verticals designed specifically for Bangladesh and Bangla code-switching (Banglish).
   - Live interactive search bar to quickly find any ecosystem tool, vertical, or AI service (e.g., search "interior", "EV", "translate", "jobs").
   - Fast status stats: Active services, Planned verticals, Target launch phases.

3. Ecosystem Explorer & Directory:
   - Filterable catalog tabs: All, AI Core (BDai.ai, BDai.app, BDai.dev, BDai.studio, BDaiHub), Verticals (Bangla.autos, BanglaEV, BanglaInterior, ApartmentsBD, FintechBangla, BanglaAgri, BDSolarpower, FashionBD, workersBD), Content & Traffic (translateBD, writeBD, BDAsk, BanglaSEO, BanglaPrompts, Bangla.education, Dhakaly).
   - Rich product cards for each service: icon/logo, category cluster badge (Mobility, Home, Money, Agri, etc.), target phase badge (Phase 1 Foundation, Phase 2 Traffic, Phase 3 Verticals, Phase 4 Devs), short bilingual description, and primary action ("Launch Tool", "Join Beta", or "Preview Roadmap").

4. Featured Vertical Spotlight:
   - Highlight BanglaInterior (Vertical #1 launching in Phase 1): interactive room redesign visual preview, photo upload teaser, before/after slider mockup.
   - Highlight BDAsk & BDai Core: interactive live demo widget showing Bangla AI prompting / query response preview.

5. Interactive 12-Month Roadmap & Architecture Visualizer:
   - Interactive 4-phase timeline (Phase 1: Foundation M1-M3, Phase 2: Traffic Engine M4-M6, Phase 3: Vertical Expansion M7-M9, Phase 4: Developer Ecosystem M10-M12) matching the v1.0 November 2026 plan.
   - Filter by phase to see milestones and exit criteria.

6. Unified Auth & Developer Access Section:
   - Early access waitlist form with phone number / OTP mockup and role selection (User, Creator, Developer, Business Partner).
   - Developer callout for BDai.dev API docs and community hub.

7. Ecosystem Footer:
   - Standardized "Part of startBD" network footer template that will be used across all network sites, with cluster links, sitemap, legal, and social links.
